# School ERP System - Approval Workflow Architecture

## 1. Introduction

This document outlines the architecture for implementing approval workflows across various modules of the School ERP system. Approval workflows are essential for ensuring proper review and authorization of critical actions such as student admissions, leave requests, financial transactions, and academic changes.

## 2. Approval Workflow Requirements

### 2.1 Modules Requiring Approval Workflows

Based on the School ERP PRD, the following modules require approval workflows:

1. **Student Management**
   - Admission applications
   - Transfer requests
   - Document verification

2. **Staff Management**
   - Leave applications
   - Reimbursement requests
   - Attendance regularization

3. **Financial Management**
   - Purchase requisitions
   - Expense reimbursements
   - Fee concession/scholarship approvals
   - Budget allocations

4. **Academic Management**
   - Curriculum changes
   - Exam rescheduling
   - Grade modifications
   - Course material approvals

5. **Administrative Management**
   - Facility booking requests
   - Event approvals
   - Policy changes
   - Vendor onboarding

### 2.2 Core Requirements

- **Multi-level Approval**: Support for sequential and parallel approval chains
- **Role-based Approvals**: Approvals based on organizational roles rather than specific individuals
- **Delegation**: Ability to delegate approval authority temporarily
- **Notifications**: Real-time notifications for pending approvals
- **Audit Trail**: Complete history of approval actions
- **SLA Tracking**: Monitoring of approval timelines
- **Conditional Workflows**: Dynamic workflow paths based on request attributes
- **Comments & Annotations**: Ability to add notes during approval process
- **Mobile Support**: Approve/reject from mobile devices
- **Bulk Actions**: Process multiple approval requests simultaneously

### 3.2 Core Components

#### 3.2.1 Workflow Engine

The central component responsible for managing workflow definitions, state transitions, and process execution.

**Key Responsibilities**:
- Workflow definition management
- Process instance creation and tracking
- State management and transitions
- Rule evaluation
- SLA monitoring

#### 3.2.2 Approval Request Service

Handles creation, modification, and tracking of approval requests.

**Key Responsibilities**:
- Create approval requests
- Track request status
- Manage request metadata
- Link requests to business objects
- Provide request history

#### 3.2.3 Approver Resolution Service

Determines who can approve a particular request based on organizational structure, roles, and delegation rules.

**Key Responsibilities**:
- Identify appropriate approvers based on workflow definition
- Handle role-based approver resolution
- Manage approval hierarchies
- Process delegation rules
- Handle escalations and timeouts

#### 3.2.4 Notification Service

Manages notifications to approvers and requesters.

**Key Responsibilities**:
- Send notifications for pending approvals
- Deliver reminders for aging requests
- Notify requesters of status changes
- Support multiple notification channels (in-app, email, mobile push)

#### 3.2.5 Audit Service

Maintains a detailed history of all approval-related actions.

**Key Responsibilities**:
- Record all approval actions
- Track who performed each action and when
- Maintain comments and justifications
- Generate audit reports
- Ensure compliance with record-keeping requirements

interface WorkflowDefinition {
  id: string;

interface ApprovalRequestCardProps {
  request: ApprovalRequest;
  onApprove: (requestId: string, comment?: string) => void;
  onReject: (requestId: string, comment: string) => void;
  onViewDetails: (requestId: string) => void;

const ApprovalRequestCard: React.FC<ApprovalRequestCardProps> = ({
  request,
  onApprove,
  onReject,
  onViewDetails
}) => {
  const [comment, setComment] = useState('');
  const [isExpanded, setIsExpanded] = useState(false);
  
  const handleApprove = () => {
    onApprove(request.id, comment);
  };
  
  const handleReject = () => {
    if (!comment.trim()) {
      // Show error - comment required for rejection
      return;
    }
    onReject(request.id, comment);
  };
  
  return (
    <Card>
      <CardHeader
        title={request.requestTitle}
        subheader={`Requested by: ${request.requestedBy} on ${formatDate(request.submittedAt)}`}
        action={
          <PriorityIndicator priority={request.priority} />
        }
        onClick={() => setIsExpanded(!isExpanded)}
      />
      
      <Collapse in={isExpanded}>
        <CardContent>
          <RequestSummary data={request.requestData} objectType={request.objectType} />
          
          <TextField
            multiline
            rows={2}
            placeholder="Add a comment (required for rejection)"
            value={comment}
            onChange={(e) => setComment(e.target.value)}
            fullWidth
            margin="normal"
          />
        </CardContent>
        
        <CardActions>
          <Button 
            variant="outlined" 
            color="primary" 
            onClick={() => onViewDetails(request.id)}

            View Details
          </Button>
          <Button 
            variant="contained"

// ApprovalButton.tsx
interface ApprovalButtonProps {
  objectType: string;
  objectId: string;
  objectData: Record<string, any>;
  title: string;
  description?: string;
  onApprovalInitiated?: (requestId: string) => void;
  disabled?: boolean;
  variant?: 'text' | 'outlined' | 'contained';
  size?: 'small' | 'medium' | 'large';
}

const ApprovalButton: React.FC<ApprovalButtonProps> = ({
  objectType,
  objectId,
  objectData,
  title,
  description,
  onApprovalInitiated,
  disabled = false,
  variant = 'contained',
  size = 'medium'
}) => {
  const [isDialogOpen, setIsDialogOpen] = useState(false);
  const [comment, setComment] = useState('');
  const [isSubmitting, setIsSubmitting] = useState(false);
  
  const { mutate: initiateApproval } = useInitiateApproval();
  
  const handleSubmit = () => {
    setIsSubmitting(true);
    
    initiateApproval(
      {
        objectType,
        objectId,
        objectData,
        title,
        description: description || title,
        comment
      },
      {
        onSuccess: (data) => {
          setIsDialogOpen(false);
          onApprovalInitiated?.(data.requestId);
          showNotification('Approval request submitted successfully');
        },
        onError: (error) => {
          showErrorNotification('Failed to submit approval request');
        },
        onSettled: () => {
          setIsSubmitting(false);
        }
      }
    );
  };
  
  return (
    <>
      <Button
        variant={variant}
        size={size}
        disabled={disabled}
        startIcon={<ApprovalIcon />}
        onClick={() => setIsDialogOpen(true)}
      >
        Submit for Approval
      </Button>
      
      <Dialog
        open={isDialogOpen}
        onClose={() => setIsDialogOpen(false)}
        maxWidth="sm"
        fullWidth
      >
        <DialogTitle>Submit for Approval</DialogTitle>
        <DialogContent>
          <DialogContentText>
            This will submit {title} for approval. Please provide any additional comments for the approvers.
          </DialogContentText>
          <TextField
            autoFocus
            margin="dense"

            multiline
            rows={4}
            value={comment}

            onClick={handleSubmit}

// PurchaseRequisitionForm.tsx
const PurchaseRequisitionForm = () => {
  const [requisition, setRequisition] = useState<PurchaseRequisition>({
    title: '',
    department: '',
    items: [{ description: '', quantity: 1, estimatedCost: 0 }],
    totalEstimatedCost: 0,
    justification: '',
    requiredByDate: null,
    attachments: []
  });
  
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [requisitionId, setRequisitionId] = useState<string | null>(null);
  
  const { mutate: saveRequisition } = useSavePurchaseRequisition();
  
  // Calculate total cost when items change
  useEffect(() => {
    const total = requisition.items.reduce(
      (sum, item) => sum + (item.quantity * item.estimatedCost), 
      0
    );
    setRequisition(prev => ({ ...prev, totalEstimatedCost: total }));
  }, [requisition.items]);
  
  const handleAddItem = () => {
    setRequisition(prev => ({
      ...prev,
      items: [
        ...prev.items,
        { description: '', quantity: 1, estimatedCost: 0 }
      ]
    }));
  };
  
  const handleRemoveItem = (index: number) => {
    setRequisition(prev => ({
      ...prev,
      items: prev.items.filter((_, i) => i !== index)
    }));
  };
  
  const handleItemChange = (index: number, field: string, value: any) => {

      items: prev.items.map((item, i) => 
        i === index ? { ...item, [field]: value } : item
      )
    }));
  };

    setIsSubmitting(true);

        setRequisitionId(data.id);

      },
      onError: () => {
        setIsSubmitting(false);
        showErrorNotification('Failed to save purchase requisition');
      }
    });
